# Source Code

SOAForge conserva **demos independientes por asignatura y parcial**.

## Planned layout

```text
src/
├── ISO-810/
│   ├── partial-1-akana-soa/
│   └── partial-2/
└── ISO-815/
    ├── partial-1-bonitasoft-bpm/
    └── partial-2/
```

### ISO-810 / P1

La demo programada respaldará la presentación de **Akana SOA** mediante un escenario pequeño de servicios/APIs, contratos, routing, políticas y gobierno.

### ISO-815 / P1

La demo programada respaldará la presentación de **BonitaSoft BPM** mediante un proceso BPM ejecutable o reproducible, con tareas, formularios e integración.

Los demos pueden reutilizar un dominio ficticio común si resulta práctico, pero deben permanecer desacoplados como entregables académicos.
