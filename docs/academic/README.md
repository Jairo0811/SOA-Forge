## Regla de organización

Cada celda de la tabla representa una entrega separada con:

- investigación propia;
- presentación propia;
- portada propia;
- integrantes según la asignatura;
- demo programada opcional/propia;
- fuentes y conclusiones propias.

El código puede compartir utilidades si conviene, pero no debe borrar la separación académica entre ambas materias.
