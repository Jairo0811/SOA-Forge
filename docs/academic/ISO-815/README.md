## Modelo de entrega

ISO-815 mantiene **su propia presentación por parcial**. No es la implementación open source de la presentación de ISO-810.

### Primer parcial — BonitaSoft BPM

El caso asignado para el primer parcial es **BonitaSoft BPM**.

La investigación académica incluye:

1. Introducción al SOA.
2. Introducción a BPM.
3. Historia y evolución.
4. Características principales.
5. Módulos de la aplicación.
6. Componentes principales.
7. Principales competidores.
8. Hardware y/o appliance para una empresa con 500 usuarios.
9. Elementos usuales que incluye una solución SOA/BPM con la herramienta.
10. Costos aproximados para una implementación de 500 usuarios.
11. Otros aspectos relevantes definidos por el grupo.
