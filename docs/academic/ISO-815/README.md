# ISO-815 — Integración de Aplicaciones con Tecnología Open Source

## Enfoque de SOAForge

La línea ISO-815 reutiliza el mismo dominio y los mismos contratos de servicio de SOAForge, pero implementa la infraestructura de integración con componentes open source.

## Objetivo

Demostrar que el problema de integración es independiente del producto utilizado y comparar cómo capacidades equivalentes pueden construirse con tecnologías abiertas.

## Stack objetivo inicial

- **Frontend:** React + TypeScript
- **Backend:** ASP.NET Core
- **Gateway:** Apache APISIX (objetivo de evaluación)
- **Identity:** Keycloak
- **Database:** PostgreSQL
- **Observabilidad:** Prometheus + Grafana
- **Contenedores:** Docker

> Las tecnologías se validarán antes de cerrar la Fase 5. La arquitectura y los contratos de negocio permanecerán comunes para ambas materias.

## Comparación esperada

La presentación ISO-815 se enfocará en integración, interoperabilidad, despliegue, extensibilidad, observabilidad, seguridad y modelo de licenciamiento del stack open source.
