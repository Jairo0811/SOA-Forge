# SOAForge Brand Assets

La identidad visual oficial de **SOAForge** utiliza una estética tecnológica empresarial con énfasis en integración, gateway y conectividad.

## Assets

- `soaforge-logo.svg` — banner horizontal principal para README, presentaciones y documentación.
- `soaforge-icon.svg` — símbolo cuadrado para favicon, avatar o portada compacta.

## Concepto visual

- **Hexágono:** arquitectura, estructura y plataforma empresarial.
- **Portal central:** gateway e integración entre sistemas.
- **Nodos conectados:** servicios, APIs, datos y aplicaciones empresariales.
- **Azul/cian:** interoperabilidad, tecnología y conectividad.
- **Ámbar/dorado:** la idea de *Forge*: construir, transformar e integrar.
